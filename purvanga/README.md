# purvanga/

*Pūrvāṅga* — the preliminary/preparatory rites common to nearly every puja, factored out here so they're written once and `\input` wherever needed from `../pujas/`, instead of being copy-pasted into each puja file.

- `aasana-puja.tex` — āsana pūjā (consecrating the seat).
- `aatma-puja.tex` — ātma pūjā (self-purification).
- `ghanta-puja.tex` — ghaṇṭā pūjā (worship of the bell).
- `guru-dhyanam.tex` — guru dhyānam (meditation on the guru).
- `kalasha-puja.tex` — kalaśa pūjā (consecrating the water vessel).
- `lokapala-puja.tex` — lokapāla pūjā (worship of the guardians of the directions).
- `matrugana-puja.tex` — mātṛgaṇa pūjā (worship of the mother-goddesses).
- `navagraha-puja.tex` — navagraha pūjā (worship of the nine planets), with an accompanying diagram (`navagraha-diagram.tex`, a standalone-class file rendering the navagraha layout, compiled to `navagraha-diagram.pdf`).
- `pitha-puja.tex` — pīṭha pūjā (worship of the deity's seat/pedestal).
- `prana-pratishtha.tex` — prāṇa-pratiṣṭhā (invoking life/presence into the image).
- `vighneshwara-puja.tex` — the pūrvāṅga Vighneśvara (Gaṇeśa) pūjā done at the start of a ritual to clear obstacles; `ganesha.pdf` is the accompanying image it includes.
