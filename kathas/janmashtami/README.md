# kathas/janmashtami/

Three tellings of Kṛṣṇa's birth, each from a different source:

- `bhagavatam-10-03.tex` — Śrīmad Bhāgavatam, daśama-skandha, adhyāya 3 (Śrī Śuka's narration of the birth itself).
- `harivamsha-krishnajanma.tex` — Harivaṃśa, adhyāya 35 (कृष्णजन्मानुकीर्तनम्), Vaiśampāyana's telling.
- `janmashtami-vrata-katha.tex` — the Janmāṣṭamī vrata katha proper (mūlam: Śrī Vrata Rāja), Kṛṣṇa explaining the vrata to Yudhiṣṭhira.
