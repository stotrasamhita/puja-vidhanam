# kathas/shravana-mahatmyam/

The Skanda Purāṇa's Śrāvaṇa-māsa-māhātmya (Īśvara answering Sanatkumāra on the glory of the month of Śrāvaṇa), 30 chapters:

- `shravana-mahatmyam-orig.txt` — the original scanned text, undivided.
- `01.txt`–`30.txt` — that text split into one file per chapter.
- `shravana-mahatmyam.txt` — the reflowed/cleaned plain-text version, reassembled from the chapters.
- `shravana-mahatmyam.tex` — the final typeset LaTeX version used in the book.
