# kathas/kartika-mahatymam/src/

Working/intermediate material behind `../KarttikaMasaMahatmyam.tex`, kept for reference rather than for direct use:

- `KarttikaMasaMahatmyam-orig.txt` — the original plain-text scan.
- `001.md`–`036.md` — that text split into one Markdown file per chapter.
- `2-वैष्णवखण्डम्.txt` — the wider Vaiṣṇava-khaṇḍa text (of which the Kārtika-māhātmya is one section) that the source was drawn from.
- `KarttikaMasaMahatmyam.txt`, `KarttikaMasaMahatmyam-transformed.tex` — reassembled plain-text and LaTeX-transformed passes on the way to the final typeset `.tex` one level up.
