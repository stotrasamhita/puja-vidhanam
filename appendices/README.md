# appendices/

Reference tables of pañcāṅga (Hindu calendrical) terminology, `\input` at the end of the book (see the "उपाङ्गाः" part in [`../pujas.tex`](../pujas.tex)). The saṅkalpa recited at the start of most pujas names the current saṁvatsara, māsa, nakṣatra, yoga, and karaṇa — the fill-in-the-blank commands for these in `../preamble.tex` (`\samvatsara`, `\nakshatra`, `\yoga`, `\karana`) link to the matching table here via `\see{...}`, so a reader unsure of a term can look it up.

- `samvatsara-names.tex` — the 60-year Jupiter/Bṛhaspati cycle of saṁvatsara names.
- `masa-names.tex` — the twelve lunar (cāndra) month names, plus a table cross-referencing them against the ṛtu (season), solar (saura) month, and the corresponding Gregorian month.
- `nakshatra-names.tex` — the 27 nakṣatras (lunar mansions).
- `yoga-names.tex` — the 27 yoga-s used in pañcāṅga reckoning.
- `karana-names.tex` — the eleven karaṇa-s (half-tithi units): the seven repeating ("cara") ones and the four fixed ("sthira") ones, plus a table of which karaṇa falls in which half of each tithi.
